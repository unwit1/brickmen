Canonical project state lives in [AUTONOMOUS_STATE.md](../../../AUTONOMOUS_STATE.md) and [data/autonomous-state.json](../../../data/autonomous-state.json). Use those files and recent Git commits before choosing the next task.

The [generation brief workflow](generation-workflow.md) is an additional preflight interface to the existing geometry, provider and evaluation pipelines. Its metadata checks do not replace semantic review, exact-hash model-input approval, digital geometry checks or physical validation.

The initial local continuation ran against an older checkout and passed 42 tests there. Integration with current GitHub history brought in the existing body-generation and semantic-review capabilities; full-suite validation and new work are recorded in canonical autonomous state. Do not use the former local geometry roadmap as evidence that those capabilities are absent.
